# 待ち状態の宣言

ユーザーの確認・行動や外部の出来事を待ってターンを終えるときは、返答の最後に次の1行を書く。Stop hook がこの行を拾い、Obsidian の `000_Inbox/Sessions/<端末名>.md` に一覧化する。

```
待ち: Apple から処理完了のメールが届いたら知らせてもらう
```

- 書くのは、ユーザーが何かしないと作業が進まないときだけ（例: 外部からの連絡待ち、ユーザーの動作確認待ち、判断待ち）
- タスクが完了して、特に待つものがないときは書かない（書かなければ一覧から自動で外れる）
- 内容は「誰が・何をしたら再開できるか」がわかる1文にする
- 行は `待ち:` で始め、装飾しない
- 機密情報（APIキー、顧客名、社内URL）は書かない。一覧は個人の GitHub リポジトリに push される
