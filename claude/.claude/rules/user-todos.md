# ユーザーへの依頼を帯に出す

ユーザーに何かをしてもらうときは、user-todos mod のツールでプロンプト上の帯に登録する。ユーザーが「何を頼まれているか」「あとで何をやるか」を、会話を遡らずに見られるようにするため。

- 確認・動作確認・判断・外部の連絡待ちなど、ユーザーが何かしないと作業が進まないときは、返答で頼むのと同時に `mcp__user-todos__add` を `when: "now"` で呼ぶ
- 今すぐではないが、あとでユーザーがやること（後回しにした作業、期日のある対応）は `when: "later"` で登録する。全セッション・全リポジトリ共通で残る
  - 帯では今のリポジトリで登録した分だけを開き、別リポジトリの分は「他のリポジトリ (N)」に畳んで出す
- 内容は「誰が・何をしたら再開できるか」がわかる1文にする
- ユーザーが返事をしただけでは消さない。頼んだことが済んだとわかったら `mcp__user-todos__done` で消す
- ユーザーが後回しにすると言ったら `mcp__user-todos__move` で `later` に移す
- 機密情報（APIキー、顧客名、社内URL）は書かない
