# screenshot-crop

## 目的

ターミナルや画面全体のスクリーンショットは、そのまま記事に貼ると文字が小さく、伝えたい部分が埋もれる。
見せたい要素を決め、その要素がちょうど収まる範囲で切り出す。

## 実行手順

### 1. 見せたいものを1つに決める

画像を Read で開き、この1枚で何を見せるかを決める（帯、ペイン、表、差分など）。
1枚に2つ以上の主題があるなら、切り出しを分けて複数の画像にする。

### 2. 表示座標を元画像のピクセルに換算する

Read の結果に `original 2926x2036, displayed at 2000x1392. Multiply coordinates by 1.46` のような注記が出る。
画面上で読み取った座標にこの倍率を掛けて、元画像のピクセル座標にする。
Retina で撮った画像は、画面の座標（ポイント）の2倍がピクセルになる。

### 3. 内容の幅で切る

切り出す範囲は、画面の端ではなく内容の端で決める。

- 文字が左側にしかない帯や一覧は、右側の空白を含めず、いちばん長い行の終わりまでで切る
- 横に極端に長い画像（目安として幅が高さの4倍以上）は、記事の本文幅に縮められて文字が読めなくなる。幅を内容まで詰める
- 上下の端で行が半分欠けないように、行の切れ目で切る

```bash
# sips -c <高さ> <幅> --cropOffset <上からのY> <左からのX>
sips -c 1020 1606 --cropOffset 540 0 in.png --out cropped.png
```

### 4. 余白を自動で詰めて、均等な余白を付け直す

背景色が一様なら、ImageMagick で外周の余白を削り、同じ色で均等な余白を付け直す。

```bash
magick cropped.png -fuzz 8% -trim +repage \
  -bordercolor "$(magick cropped.png -format '%[pixel:p{0,0}]' info:)" -border 24 out.png
```

カーソルや薄い罫線が残ると trim が効かない。その場合は手順3の範囲を詰め直す。

### 5. 写ってはいけないものを確認する

切り出した画像を Read で開き、次のものが写っていないかを確かめる。
写っていたら、範囲を変えるか、原因を消して撮り直す（塗りつぶしで隠すより撮り直しを優先する）。

- 通知（Slack など。社名や業務の内容が出やすい）
- tmux のステータスバーやウィンドウ名、ほかの作業のリポジトリ名
- マウスのホバーで付いたハイライト（マウスを外してから撮り直す）
- 入力欄の候補表示（ゴーストテキスト）やカーソル
- 本題と関係ない個人のパス、メールアドレス、トークン

### 6. 書き出す

記事に使う場合は webp にする。文字が主体の画像は画質を高めにする。

```bash
cwebp -quiet -q 90 out.png -o out.webp
```

## 出力

- 切り出した画像のパス
- 何を見せる画像か（alt テキストの案として1文）
