# セッション検索

## 目的

`~/.claude/projects/<encoded-cwd>/<session-id>.jsonl` に残るセッションログを内容で検索し、
目的のセッションを特定して復元コマンドを渡す。

## 実行手順

1. ユーザーの説明から**ログに実際に出現しそうな語**を 1〜3 個抽出する
   - 機能名・ファイル名・識別子・ブランチ名・エラーメッセージなど、原文のまま出る語を優先
   - 「実装した」「調査した」など動作を表す語はログに出ないのでキーワードにしない
   - 日本語と英語の両表記がありうる場合は、まず英語の識別子（`submitMonthlyWorkReport` 等）で試す
2. スクリプトを実行する

   ```bash
   python3 ~/.claude/skills/find-session/scripts/search-sessions.py <キーワード...> [--any] [--all-projects] [--limit N]
   ```

   - 既定はカレントプロジェクトのみ・全キーワード AND 一致
   - ヒットが 0 なら `--any` やより短いキーワードで再試行、それでも 0 なら `--all-projects`
   - ヒットが多すぎる場合はキーワードを増やして絞る
3. 候補が複数残る場合は**編集ファイル一覧**で用途を判別する
   - 「実装」を探しているなら `src/` 配下の新規 Write が多いセッション
   - 「レビュー」「調査」なら編集が少なく該当プロンプトが議論調のセッション
4. 結果を報告する（下記形式）。候補が複数あるときは主候補を 1 つ選び、他は関連として併記する

## 出力形式

```
## 該当セッション

**`<session-id>`**（<期間>）

​```bash
cd <cwd> && claude --resume <session-id>
​```

根拠:
- <そのセッションで編集/作成された代表ファイル 3〜6 件>

関連セッション（あれば表で）
```

## 注意

- `claude --resume <id>` は**そのセッションの cwd で実行する**必要があるため、常に `cd` 込みで提示する
- セッションログは巨大（数 MB〜十数 MB）なので、`cat` や Read で全体を読まない。スクリプトの出力で判断し、
  さらに詳細が要る時だけ `python3 -c` で当該 jsonl から必要部分のみ抽出する
- 現在動作中のセッション（`--resume` 先が起動中）は復元できないことがある。日時が直近なら一言添える
